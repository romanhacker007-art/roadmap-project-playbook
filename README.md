# roadmap-project-playbook

A Claude Code skill: a method for multi-session infrastructure and migration projects (server + laptop, SSH, Tailscale, git, network routing). Roadmap + step framework + context files + one task per session, every conclusion marked "fact" or "guess".

Install: copy `skills/roadmap-project-playbook` to `~/.claude/skills/`. The text is in Russian. `templates/FRAMEWORK.md` is a ready 11-step template.
